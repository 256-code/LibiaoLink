# docs/rules · 规则文案与金标基准

- 用途：存放自动化规则（R01~R07 及后续 A 系列）的**逐字文案**与**金标用例骨架**，作为规则引擎实现的比对基准（M0-04 产出）。
- 归属：wmj（后端领域 / 自动化）；评审 lan、px。
- 约定：
  1. 本目录文案为「逐字基准」——消息标题与内容不得改字，变量占位符（如 {任务描述}）保持原文格式；实现侧模板与本文档逐字比对（金标回放，见 技术设计v0.3-实施与验收.md M5 出口标准）。
  2. 规则触发窗口的时间口径按 ADR-028（Asia/Shanghai）；幂等与投递保证按 ADR-005 / 技术设计v0.2 §6.2。
  3. 原文未说明或存在两种理解的点，一律以「待确认」显式登记，不静默选择（见各规则条目与文末清单）。
  4. 文案变更走独立评审：改文案 = 改金标，必须同步更新本目录与金标用例编号。
  5. A 系列（A01 / A02 / A03 / A14）原文未给逐字文案 —— 该目录文件为先行**建议稿**，业务回执后按结论改文案与断言（待确认点逐条登记，不静默选择）。
- 文件：`R01-R07-内置规则文案.md`（一期七条内置规则 · 需求说明书原文逐字）、`A01-A03-A14-扩展规则文案.md`（一期四条扩展规则 · **建议稿** + 待确认清单 + 金标用例对照）。

## 来源

需求说明书 V1.0 §6.1「原清单 7 条规则逐条落地」（原文逐字）；系统功能书.md C2-02；技术设计v0.2-架构与数据模型.md §6。
