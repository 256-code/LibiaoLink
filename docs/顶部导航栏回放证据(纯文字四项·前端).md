## 口径落地（实现处）

- 组件：`frontend/src/components/TopNav.tsx` —— 四项 = `#/`（`HUB_HASH`）、`projectsHref()`（列表页带本地筛选记忆）、`#/templates`（`TEMPLATE_BASE_HASH`）、`#/my-tasks`（`WORKSPACE_BASE_HASH`）；当前页 = `aria-current="page"`（列表页与项目详情都算「项目空间」；任务模板页只认 `placeholder / page === "templates"`）。
- 样式：`frontend/src/app.css` 的 `.topnav` / `.topnav-btn` / `.topnav-btn:hover` / `.topnav-btn[aria-current="page"]` / `.topnav-btn:focus-visible`（+ `prefers-reduced-motion` 下关过渡）—— 只有字号 / 行高 / 字距 / 内衬 / 配色 / 颜色过渡与焦点圈；面、描边、高光、阴影、缩放、rotate3d 都不在了。
- 顶栏：`AppHeader.tsx` 在 Logo 右侧渲染 `<TopNav />`，并删掉原来的大页名分支（`Home.tsx` / `WorkspacePage.tsx` / `PlaceholderPage.tsx` 同步去掉 `title=`）；`<768px` 由 `hidden md:flex` 整排隐藏。
- 历史口径（已下架，留档）：Push 236 首版按样张做的是四枚**玻璃胶囊**（`linear-gradient(-75deg, …)` 玻璃面 + 三层 `inset` 内阴影 + `backdrop-filter` + conic 描边环 + `mix-blend-mode: screen` 高光扫过 + 悬停 `scale(.975)` + 按下 `rotate3d(1,0,0,25deg)`）—— 四轮收口后全部删除，`@property --topnav-angle-*` 一并删掉。
