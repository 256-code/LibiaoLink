# Push 188 回放证据（前端：入口页改版 —— 左侧竖排三胶囊 + 右侧平面世界地图（逐国可触碰·中国标准地图口径）＋ 项目蓝色底色（档位随数据算）与「触碰才出柱」+「点一下国家区域钉住」（项目地区联动 · 立柱停留 · 清单可滑动 / 可展开））

> 业务口径：px 2026-09-24「在首页做一个地图 把首页三个胶囊放到最左侧上下排列 右侧部分则建一个平面地图 如图所示 但是鼠标触碰有动画效果」；
> 追订「参考图的蓝点不需要」「我想要各个国家都可以展现」，以及复核意见「台湾怎么回事」「你要再审查一遍 地图上的国家中国认不认可」。
> 再追订「**新加坡为什么标不出来**」（110m 数据里没有微国的几何）→ 已补**微国符号层**：29 个主权小国一个不漏，可触碰报国名。
> 三追订「**这是中国标准的地图eps数据文件 你参考一下**」→ 拿《世界地图（分国设色）》**审图号 GS(2016)1663号** 的 EPS 原件做口径比对，补齐**南海诸岛符号层**（业务口径「细小的岛屿不用列」→ 砍成**群岛代表点 5 点**：东沙 / 西沙 / 中沙 / 南沙 / 南沙南部·曾母暗沙一带 各一点；触碰报「中国」）；比对结论见 docs/入口页地图口径审查(中国标准地图·前端).md 第七节。
> 四追订「**这个地图做好是要和我的项目地区联动的 哪个项目做哪个地区 然后地图这个国家就保持鼠标悬停的效果 然后有立柱展示项目梳理**」→ 已补**项目立柱层**：一个有项目的国家一根柱（高度 = 项目数、分段 = 项目状态），触碰立柱 = 触碰该国，右上角出「项目梳理」清单，点柱进「项目空间」按该地区筛选（见下「项目立柱怎么验的」）。
> 五追订「**有项目的国家 轮廓显示并且整体国土区域颜色也是蓝色  图二的这种蓝**」→ 有项目的国家 / 微国改成**蓝底（`#4285f4`）+ 蓝轮廓（`#1a73e8`）**、触碰压深一档 + 白轮廓，没有项目的国家保持浅灰。
> 六追订「**这个柱子重叠太严重了 还有没有别的方式来展示**」→ 先摆 5 个方案（现状立柱 / 比例圆点 / 分级底色 / 密集区聚合 / 静止只上底色·触碰才出柱）给业务选，业务定**方案 E**：**静止态一根柱都不站**，国家 / 微国按项目数上**蓝色底色**（档位随数据算、最多 5 档），**鼠标触碰才长出立柱** + 右上角项目梳理清单（见下「蓝色底色与「触碰才出柱」怎么验的」）。
> 七追订「**这个颜色深浅不能按照固定的数据来 到时候所有地区大于3个不就是同一个颜色了吗**」「**为什么有些柱子是图二的状态**」→ ① 底色档位从写死的三档改成**随数据自适应**（按当前分布算、最多 5 档，同档同色、项目越多越深）；② 立柱分段从灰蓝深浅改成**四色各表状态**（进行中蓝 / 已暂停橙 / 已完成绿 / 已归档灰）+ 柱顶椭圆跟最上段同色（原来「已归档」那段几乎白，看着像没渲染完）；③ 图例「项目数」组尾报一句**「按当前数据自动分档 · 共 N 档」**（N 就是算出来的档数，「项目数」字头与这句都挂 `title` 口径说明）—— 落业务再追订「**这个标准应该是动态的 有一套计算标准 不是定死的**」；④ 八追订「**那这个数据要换吧 不能写的这么死 改成一档二档…**」→ 图例**只报档位名**（一档 / 二档 / … / 最多五档，档数跟着数据走），每档具体是几个项目挪到那一项的悬停说明（`title` = 「一档：1 个项目」这种）—— 图例里再也看不到写死的条数文案。|
> 九追订「**当鼠标停留时间大于4s时立柱停留 同时右侧的列表可以滑动或者展开**」→ 业务改口「**不要改成4s了 改成点击国家区域即可**」「**点击空白区域也可以取消定住**」：**点一下有项目的国家 / 微国就把立柱与右上角「项目梳理」钉住** —— 鼠标走开也不收回（腾出手去清单里滑动 / 点「展开全部」看全量），再点一次同一国、按 Esc、点海面空白处、或点清单上的「×」解除，点别国就把钉子挪过去（只碰不点不会钉）。
> 本刀把入口页从「正中一排胶囊」改成「**左侧竖排三胶囊 + 右侧平面世界地图**」，底图**逐国可触碰**；

## 蓝色底色与「触碰才出柱」怎么验的（脚本里的硬断言）

- **静止态一根柱都不露面**：42 根柱的 `data-shown` 全是 `false`、柱身 `opacity` 都是 `0`、命中矩形 `pointer-events: none`（收起时不占命中，不挡下面那些国家的触碰）—— 这一条就是「柱子重叠太严重」的正解，断言直接锁死。
- **分档与库内逐条对**：脚本直连 `projects`（未删项目）按 `region` 分组、用**地区字典解析后的展示名**归拢（`阿联酋 → 阿拉伯联合酋长国` 这种别名也能对上），再按**和前端同一套算法**（`buildTierBounds` / `tierIndex` / `tierSlot` / `tierText` 四段逐行照抄）算预期档位与色阶槽位 —— 42 根柱的**根数、每根条数、合计（本次 108 个项目 / 42 个国家/地区）**、每根柱顶计数标签、以及每国 `data-tier` 与 `fill` 必须同时对上；并断言「每档都落到了图上」（本次按 108 个项目算出来 4 档 —— 一档 1 个项目 / 二档 2 个项目 / 三档 3–4 个项目 / 四档 5 个及以上：中国 8 = 四档、英国 4 = 三档、新加坡 1 = 一档）。图例里还直接把档数报出来：「按当前数据自动分档 · 共 4 档」—— 档数与边界都是算出来的，脚本按同一套算法逐国对账。|
- **灰底对照组**：库里没有项目的国家 `data-tier=0`，仍是浅灰底 `rgb(231, 233, 238)` + 无色轮廓（墨西哥 / 阿尔及利亚）。
- **触碰才出柱（真机鼠标坐标）**：把鼠标停在该国国境内（取样点**特意避开立柱命中带**，免得指针刚碰到国家就被刚长出来的柱挡住）→ 等 780 ms（柱身 620 ms 过渡）→ 断言**只有这一根** `data-shown=true`、柱身 `opacity=1`、命中区可点（`pointer-events: all`）、柱顶计数已展开；同一次触碰还要断言该国**压到最深触碰色**（`rgb(26, 115, 232)`）+ 白轮廓、徽标加报「N 个项目」、柱与国家互相 `data-linked`。
- **移开就收**：鼠标移开 → 全部柱 `data-shown=false`、该国还原到**本档**底色（英国 = 第 3 档 `rgb(82, 144, 244)`）+ 蓝轮廓；触碰**没有项目的**国家（墨西哥）时一根柱都不露面、也不出项目清单。
- **落点在国界里**：每根国家立柱的锚点（视口坐标）用国界路径自带的 `isPointInFill` 判，必须在国境内（不站海里）；锚点算法在 `data/mapProjects.ts`（最大子路径的包围盒中心，凹形状走 7 × 7 网格采样）。
- **高度随项目数**：项目数最多的柱不矮于项目数最少的柱。
- **项目梳理清单**：触碰立柱时右上角浮层列出该国项目，项目名与库内一致（本次英国 = 英国展厅 / 英国物流分拣）。
- **点柱进项目空间**：方案 E 里柱是碰出来的，所以脚本按真实路径走 —— 先碰国家把柱叫出来、再移到柱上、再点；点完地址栏变成 `#/projects?filter[region]=…`，按该地区筛选。
- **立柱分段四色**：触碰后有柱时读柱身各段（`rect.hub-map__pillar-seg`）的 `data-status` 与计算样式 `fill` —— 每段填充必须等于四色表（进行中 `rgb(26, 115, 232)` / 已暂停 `rgb(242, 153, 0)` / 已完成 `rgb(30, 142, 62)` / 已归档 `rgb(154, 160, 166)`），段集合与库内该地区的状态分布一致；柱顶椭圆（`data-top-status`）必须等于**最上面那一段**的颜色（本次抽查：英国 4 个项目 = 进行中 3 + 已完成 1 → 柱顶 `data-top-status=done`、柱顶色 `rgb(30, 142, 62)`）。
## 点一下国家区域钉住怎么验的（九追订：立柱停留 + 清单可滑动 / 可展开）

- **只碰不点不会钉**：鼠标停在有项目的国家上（柱长出来、徽标加报项目数）—— 这时 `data-pinned` 一根都没有、右上角浮层的 `pointer-events` 还是 `none`（钉住之前清单**不吃鼠标事件**，不抢底图的触碰），徽标上加了一句「点一下钉住」把动作说破。
- **点一下 → 钉住**：真实鼠标点在国家**国境内**（取样点同样避开立柱命中带）→ 该柱 `data-pinned=true`、浮层 `data-pinned=true` / `data-active=true` / `pointer-events: auto`（能滚能点）、表头挂出「展开全部」+「×」，徽标加一枚「已钉住」小签。
- **鼠标走开也不收回**：把鼠标移到清单上再读一遍 —— 柱与清单都还在（`data-shown=true` / `data-active=true`），国名徽标仍是「中国 8 个项目」、中国国土仍是压深色（`data-linked` 留在钉住的那国）—— 这就是「立柱停留」（旧版鼠标一离开就收）。
- **清单可滑动**：浮层里 `.hub-map-projects__list` 的 `overflow-y` 是 `auto`，钉住时**列全部项目**（不再截 6 条），可视区高度压着（本次 112px 装 8 条 → `scrollHeight` 178px），脚本把 `scrollTop` 拉到底、断言 `scrollTop > 0`（本次 66）—— 「列表可以滑动」验的是真滚动，不是文案。
- **可展开**：点表头「展开全部」→ 清单放开高度上限（可视区 112px → 178px）、8 条全装下不再滚（`scrollHeight <= clientHeight`）、按钮文案转「收起」。
- **钉子能挪 / 能拔**：点别国（美国 7 个项目）→ 钉子挪过去（`data-pinned` 换成美国、清单国名与条数跟着换、展开态复位）；再点一次同一国 → 解除；钉回来后按 `Esc` → 解除；**点海面空白处（事件目标是 svg 自己）也能解除** —— 三条路各自断言。

## 蓝色底色怎么验的（谁蓝谁不蓝 / 谁深谁浅 —— 档位随数据算）

- **同屏对照**：有项目的 42 个国家/地区在**静止态**就按项目数上蓝色底 —— **档位与色阶槽位由当前数据算**（本次 108 个项目 / 最多的国家 8 个 → 4 档）：第 1 档 `rgb(200, 220, 252)`、第 2 档 `rgb(163, 198, 250)`、第 3 档 `rgb(82, 144, 244)`、第 4 档 `rgb(47, 111, 224)`（业务给的那个蓝 `#4285f4` 落在最深端这一族里），各档一律配深蓝轮廓 `rgb(26, 115, 232)`；没项目的国家（墨西哥 / 阿尔及利亚做对照组）仍是浅灰底 `rgb(231, 233, 238)`、无色轮廓。
- **微国同理**：微国符号层同一套分档 —— 有项目的新加坡（1 个）是**浅蓝点 + 深蓝镶边**（点位只有 2.4 个视口单位，纯浅蓝在浅色底上认不出来，所以按档上蓝、再补一圈 `rgb(26, 115, 232)` 镶边），触碰压深为 `rgb(26, 115, 232)` + 白镶边；没项目的安道尔是灰点（`data-tier=0`）。
- **触碰再压深一档**：触碰 / 联动的有项目国家一律从**本档**压到最深的触碰色 `#1a73e8` + **白轮廓**；鼠标移开还原成**本档**底色 + 蓝轮廓（还原态单独断言了一条 —— 验的就是「还原到本档」，不是一律回到最深档）。
- **色值出处与落点**：色阶 5 档 `#c8dcfc / #a3c6fa / #7facf7 / #5290f4 / #2f6fe0` 落在 `frontend/src/app.css` 的 `.hub-map__country[data-tier=…]` / `.hub-map__micro[data-tier=…]`（连图例色块一起）；**哪一档对应几个项目由 `frontend/src/components/HubMap.tsx` 的 `buildTierBounds()` 按当前数据算**（同档同色、项目越多颜色越深，最多 5 档），`tierSlot()` 把档数少于色阶档数时的色阶「拉开」用（三档 → 槽位 1 / 3 / 5，四档 → 槽位 1 / 2 / 4 / 5，最深档永远取最深的槽位）；业务给的参考图那个蓝（`#4285f4`，`屏幕截图 2026-09-24 112515.png`）落在最深端这一族。
- **含义**：蓝底深浅 = 「这个国家/地区有多少个项目」（数据义、不是装饰），左下角图例第一组写着「项目数：一档 / 二档 / 三档 / 四档」（档位名跟着算法算出来的档数走，每档几个项目在那一项的悬停说明里）；图例里还直接写着「按当前数据自动分档 · 共 N 档」（N 跟着数据走）—— 档数、档位边界、每档范围都是算出来的、不是写死的；精确条数仍然靠**触碰后**的柱顶计数 + 项目清单读。|

- **立柱的数据口径**：联动键是 `projects.region`（字典 region 的码）；地区条目要写成国家名（中国 / 美国 / 英国……）才落得到图上，写不成国家的（例如「华东」「海外」）进面板左下角的「未落到图上」计数、不画柱 —— 要不要给字典条目加一个「关联国家」字段，等业务口径（现在是纯前端按名字匹配，重名歧义（如「刚果」）按「对不上」处理）。

- **立柱的交互边界**：右上角浮层在**钉住前**是纯展示（`pointer-events: none`）、钉住后才接通鼠标（可滚 / 可展开 / 可关）；点柱只到「按地区筛选的项目空间列表」；要「点清单某一行直接进项目详情」「键盘可达（现在柱只响应鼠标）」这两个能力，另起一刀。

- **柱子是「碰出来」的，钉住靠点击（九追订）**：鼠标一离开该国（又没落在柱上）柱就收回；**点一下国家区域就把柱与清单钉住**（鼠标能走开、清单可滑可展），再点一次同一国 / `Esc` / 点海面空白处 / 点清单上的「×」解除。残余：柱只响应鼠标（没有键盘可达的「钉住」入口）、清单行还不能直接点进项目详情。

- 蓝底国家上**不再叠文字**：国名与项目数走左上角徽标 + 立柱计数 + 右上角浮层，底图保持干净（也避免中文小字糊成一团）。
