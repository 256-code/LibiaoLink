## 七、收集话术（2026-10-10 · Step 1 发起 · 可直接转发）

> 口径：只问「是否提供 / 结果」；Secret / webhook 值只走密钥渠道回传（不回群、不贴文档、不进 Git —— CONTRIBUTING §12）。

### 7-1 致企业微信管理员（A1 ~ A6）

> 你好，LibiaoLink 项目要接入企微消息推送（PoC 验证），需要以下信息 / 确认（凭据类的请单独私发，不要发在群里）：
> 1. 自建应用凭据 CorpID / AgentId / Secret —— 并请确认消息推送是否**复用现有 SSO 的自建应用**（A1）；
> 2. 是否需要配置「企业可信 IP」？如需要，我们先给出网 IP 清单再报白名单（A2）；
> 3. 应用「可见范围」能否覆盖全体需接收提醒的同事？（A3）
> 4. 企业策略是否允许成员在群内添加「群机器人」？（A4）
> 5. 应用消息的接口频率 / 日配额口径（后台数值或官方口径均可）（A5）；
> 6. 能否提供一个测试群 + 测试账号用于验证（避免打扰业务群）（A6）。

### 7-2 致业务 / 项目经理（B1 ~ B5）

> 1. 各位在用的项目群：请在群内添加「群机器人」后，把 webhook 地址**单独私发**（B1；不要发群里）；
> 2. 另请建好「管理员告警群」并私发它的群机器人 webhook（系统告警出口用）（B2）；
> 3. 项目群绑定由谁维护：项目经理本人，还是管理员统一维护？（B3；默认建议：项目经理 · `project.update` 档）
> 4. 群播报发送失败时降级给谁：项目经理站内信收件箱，还是再补管理员告警群提示？（B4；默认建议：项目经理站内信 + 告警群留痕）
> 5. 日报汇总这类长内容超长时怎么处理：尾部省略并标注「已截断」，还是只保留前 N 条？（B5；默认建议：尾部省略 + 截断留痕）

### 7-3 致运维 / px（C1 ~ C3）

> 1. 生产 / 测试环境的**固定出口 IP**（A2 白名单前置；`deploy/` 目前仅本地沙箱）（C1）；
> 2. `WECOM_*` 与 `OUTBOX_ALERT_WECOM_WEBHOOK` 的生产**密钥注入渠道**（C2）；
> 3. 测试环境到 `qyapi.weixin.qq.com` 的**网络可达性 / 白名单策略**（决定真机实测落点）（C3）。
