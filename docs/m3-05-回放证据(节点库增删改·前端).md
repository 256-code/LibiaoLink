## 覆盖口径

- **读**：左列「任务节点」= `GET /api/v1/task-nodes?stage=`（计数 / 卡片 / 首张与接口一致；每张卡片都带编辑 + 删除按钮）。
- **新增**：列头「＋ 添加节点」→ 内联表单 → `POST /api/v1/task-nodes`（落库、`seq` = 该阶段末位 + 10、同阶段同名 409 `NODE_ALREADY_EXISTS` 就地提示且不重复落库）。
- **编辑**：卡片铅笔 → 表单预填 → `PATCH /api/v1/task-nodes/{id}`（同一行改名 + 英文名、`version` 0→1、审计 `action=update` + 字段级 `changes`；左列卡片换新名）。
- **删除**：红胶囊 → 底部确认条 → `DELETE /api/v1/task-nodes/{id}`（物理删行、审计 `action=delete`、左列卡片消失）；**已按该节点生成的项目任务不受影响**（任务仍在）。
- **同源**：项目总览「添加任务」卡片的「任务节点」标签 = 同一份节点库（能看到刚建的节点）。
- **零残留**：跑完临时节点物理删、临时任务逐条软删、临时项目软删、临时会话撤销；临时调试脚本 `_tmp-*.mjs` 已删。
- **视觉复验（2026-09-24 修订 · 业务口径「为什么我鼠标放上去全显示了 我不要这样的」）**：模板面板的删除按钮改命名 group `group/panel`（`RowDeleteButton` 加 `scope`）—— 悬停面板空白处 = 卡片按钮全灭、只有标题行那一枚亮；悬停某张卡片 = 只有那张卡片的垃圾桶亮。三项均截图核对通过。
