## 决策记录

- **键帽文案正名（本刀）**：`CTRL V` → `Ctrl + V` —— ① 中间补「+」（快捷键通用写法）；② 大小写照业务文案、**去掉 `uppercase` 变换**（正名前由 CSS 把 `ctrl v` 变换成大写显示）。断言核两件事：左半文本 = `Ctrl + V`（空白归一后逐字比对）且键帽 `text-transform = none`（若 `uppercase` 回来会立刻挂）。
- **键帽材质与结构零改动**：渐变底 + 三层内阴影、左右分半、右半文件 / 云图标、两个原生文件框、无障碍名（「复制粘贴（点一下再按 Ctrl+V 粘图）」）全部照旧 —— 本刀断言与 Push 202 的 60 项一起跑，全绿。
