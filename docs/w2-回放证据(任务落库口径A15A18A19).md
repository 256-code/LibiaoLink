## 验收对照（A15 / A18 / A19 / A20）

- A15「阶段允许为空（临时任务）」= A1 ~ A7 / C8：不传或显式 null 都落 stageKey=null；默认读序未分组在九阶段之后；阶段完成度（GET /projects/{id}/stages）只算带阶段任务，未分组不计入。
- A18 / A23「负责人允许为空（待分配）+ 可多位」= B1 ~ B7：显式 ownerIds=[] = 待分配（不兜底项目经理）；传数组 = 分配（原顺序即展示顺序）；不传 = 不改；再置 [] = 清空（卡片拖进「待分配」列）。
- A19 / A20「顺序持久化」= C1 ~ C7：插入位次与拖动重排写 tasks.sort_index（组内 0 起、密集），刷新后不变；越界 = 组尾；旧 version 409 且不部分生效；组之间互不影响。
- 契约与落库一致性：tasks.sort_index 由迁移 0015 落库（回填按迁移前默认读序，迁移前后读序一致）；shared 的 Task / TaskCreateBody / TaskUpdateBody 与 Drizzle schema 同步（check:db-schema：27 表 · 265 列 · 77 索引 · 75 CHECK 一致）。
