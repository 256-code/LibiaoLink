# 地区按洲分组回放证据（首页筛选侧栏可展开 + 整洲筛选 · 新建项目地区 = 分洲可搜索纯选择器 · 前端）

> 口径：业务定案 2026-09-28 —— 「我觉得这里太乱了 要根据各个州分类 可以展开 这边要改那新建项目选择地区应该也要改 是不是要加一个国家地区选择器可搜索的那种」；同日追订 —— 「新建地区手打容易出问题吧 还是改成搜索选择器吧 同时筛选比如某一个洲点击可以直接筛选整个洲」→「筛选框不要改成那样的 改成这样的（动效复选框参考代码）放在筛选框最右侧即可 点击选择复选框就是筛选此区域」→「复选框太大了 要小一点 迷你一点」→「新建项目里面的地区想改成这样的 不支持手填和 删除 直接改成这样的搜索选择器 图片是英文的 我要中文的 只要选择项目 不要添加地区了 只要直接选择即可」→「还是要之前的小窗 然后最上方是已有项目地区」→「小窗做分页 已有项目地区 / 全部地区 然后选中标蓝即可 不要这个勾」→「新建项目不要默认英国 默认为空即可 然后下面的中文提示不需要」→「两个分页的高度位置要一致」。
> 落地：「地区」= 首页筛选侧栏按洲（亚洲 / 欧洲 / 非洲 / 北美洲 / 南美洲 / 大洋洲 + 其他）分组、可展开收起；**洲行最右侧一枚迷你动效复选框 = 整洲筛选**（勾上 = 该洲全部地区一起选中并展开，再点全取消）；新建 / 编辑项目的地区 = **贴字段弹出的「之前的小窗」（Push 195）**：顶部搜索框 + 「已有项目地区 / 全部地区」两页签，选中标蓝（不带对勾），两个页签固定同宽同高、同一落点；**新建默认不带地区**（占位「请选择地区」，未选不可提交）；**「＋ 添加地区」与行内删除已撤下（Push 194）**：只从候选里直接选择，不能手填 / 添加 / 删除；地区字典的新增 / 删除由种子 / 后台维护面负责。
