## 口径说明

- 「主标签栏自身 59px」= `pt-3`（12）+ 标签按钮（`py-3` 12×2 + `text-sm` 20 + `border-b-2` 2 = 46）+ 容器底边 1；两层吸顶的叠位常量 **123 = 64 + 59** 同时写在 `TaskBoard.tsx` 与 `ReportIssuePanel.tsx` 的吸顶类上，回放 ⑥ 组两处都断言「= 主标签栏下沿」，改高度会直接红。
- 键帽投影口径（em，13px 字号）：7 层侧壁最深 `0.425em ≈ 5.5px` + 末层落影 blur `0.5em ≈ 6.5px` ≈ **12px**；下内衬 16px 把整条投影兜进横幅（回放断言 nav 底 - 键帽底 ≥ 12px，实测 16px）。
- 「问题看板」放大镜按业务口径**不照搬**：原 SVG 的 24 视框 / 黑填充 / SVGRepo 外壳都去掉，只留 path —— `fillRule="evenodd"` 保住镜圈内孔，`fill="currentColor"` 随字色（当前项黑字、未选项中灰）。
- 本刀**无 DDL / 无契约改动、无新增运行时依赖**；`npm run typecheck` / `npm run build` 全绿（包体 650.35 kB）。
