## 汇总

- **42 / 42 项全过**（脚本自清理：任务逐条软删 → 项目软删读面 404 → 临时会话撤销）。
- 覆盖到的关键口径：汇总卡「最慢 / 最新阶段」= 服务端 `GET /projects/{id}/summary`（「当前阶段」已下线）；紧急重要度三档；
  四格进度写回（`status=done / progress=1 / actualEnd` 服务端联动）；状态下拉五态齐备、覆盖边界与原型一致
  （**已完成写 overdue 不生效、未完成写 overdue 生效**，覆盖值仍落库 `status_override`）；添加卡片按预设节点落库并置灰「已添加」；
  409 版本冲突出提示条 + 自动整表重取（重试可写、后台改的字段保留）；人员任务分配 / 任务进展 / 甘特图三块视图同一份服务端数据。
- 页面控制台无异常（仅 vite 连接日志、React DevTools 提示与一条预期内的 409 网络错误）。
- 脚本侧踩坑留档：① 行定位不能用「往上找第一个含标题的祖先」—— 表格容器包住整张表会串行，命中条件收紧为「这一层里同名格子只有 1 个」；
  ② 建任务不传 `ownerIds` 时服务端按项目经理兜底（要「待分配」得显式传 `[]`，见 task.service.ts:206）；
  ③ 预设节点的按钮文案是「标题 + titleEn + ＋ 添加」连写，标题要从接口新行取。
