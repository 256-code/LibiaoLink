# ADR-008 三维与 CAD 查看策略：二维条件性交付 + 三维自建（开源优先）

- 状态：草案（Proposed）｜评审：lan、px｜随 PR 合并 main 后转「已采纳（Accepted）」
- 日期：2026-09-18｜决策人：wmj（技术负责人）
- 依据：技术设计v0.1-选型分析.md §0.1、§4.8、§5（#9）、§8.2 Q4

## 背景

CAD / 三维预览是全项目技术风险最高的单点；「不允许上传第三方云」为硬约束（Autodesk Viewer 等云端方案已排除）。业务同时确认：3D 在线查看若无开源或现成组件，接受自研。

## 决策

- **二维 CAD：条件性交付**。阶段 0 用设计部门提供的真实样本做 PoC 达标判定：达标即一期上线；不达标即降级为「仅下载」——降级不影响整体上线。
- **三维在线查看：自建路线**。开源 / 现成组件优先；无合适组件则自研查看器。默认随二期实施，一期保留上传 / 下载 / 关联管理入口。
- **数据不出内网**：任何预览方案不得将图纸上传第三方云。
- 一期交付物：上传 / 下载 / 版本 / 关联；预览能力按 PoC 结论有条件交付。

## 备选与不采用原因

- Autodesk Viewer 等云嵌入：已排除（不允许上传第三方云）。
- 设计端提供轻量预览件：依赖设计部门流程改造，作为备选 / 过渡路径评估。
- 商业 SDK：仅当无开源方案可行时评估（成本与许可需单独立项）。

## 影响与后果

- 工期不因 CAD 阻塞：条件性交付 + 明确降级路径（v0.1 §7.4）。
- 三维自研是二期最大的不确定项：需在二期启动前完成组件评估（覆盖格式、交互要求：旋转 / 剖切 / 测量）与样本收集（Q4）。
- 一期 UI 需提前设计「预览不可用 → 下载」的降级提示。

## 切换触发条件

- 二维 CAD PoC 不达标 → 一期降级「仅下载」；
- 三维样本评估无合适开源组件 → 启动自研评估或暂缓，并回写本 ADR。
