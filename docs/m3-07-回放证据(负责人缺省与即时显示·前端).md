## 汇总

- **25 / 25 项全过**（脚本自清理：任务软删 → 项目软删 → 节点物理删 → 临时会话撤销，库内零残留）。
- 覆盖到的关键口径：① **缺省 = 「待分配」** —— 添加任务不带 `ownerIds` 时服务端落 `[]`；夹具特意把项目经理设成回放用户本人，
  所以这条断言同时证了「不再兜底项目经理」（兜底若还在，落库会是 `[潘兴]`）；② **即时可见** —— 勾一位 / 再勾一位 / 取消一位，
  全程不刷新页面、单元格当次就变（`replaceRow` 走 `toUiTask(view, row, resolveName)`，姓名按用户目录补全）；
  ③ **真落库** —— 每一步都对过 `tasks.owner_ids`，硬刷新后仍成立。
- 脚本侧踩坑留档：① 同一个 hash 的二次 `Page.navigate` 会被浏览器当同文档导航 —— SPA 不重挂，脚本一律「先 about:blank 再进项目页」；
  ② 关行内浮层要点**浮层外**（`usePopover` 的关闭监听在 `document` 的 `mousedown` 上）：脚本在 `document.body` 上派发 `mousedown`，
  合成 `click()` 不触发关闭；③ 「添加任务」卡片按 Esc 关（`StageAddCard` 的 keydown 在 window 上，`document` 上派发会冒泡到它）。
