## 决策记录

- **表格放大 = 字号 / 内边距 / 最小宽度三件套**：「日报记录」整表 text-sm（14px）+ td py-4（16px）/ th py-3.5（14px）+ min-w-[1080px]；行高随 pre-line 多行内容自然撑开（业务样 = 图 2 的多维表格：行更高、留白更足）。
- **换行口径两层落地**：输入层 = 多行框里真键盘 Enter 换行（表格列 white-space: pre-line 原样呈现，不再折叠空白）；展示层 = 「当日完成工作 / 明日计划」两列 pre-line + break-words。
- **自动序号 = 预置 + 续号 + 统一重排**：空框聚焦预置「1: 」；回车在光标处插入「换行 + 下一行序号」（2: / 3: …）并回置光标；失焦 / 提交前 renumberLines 剥掉行首旧号（1: / 2. / 3、/ 4：等）→ 去空行 → 按 1: / 2: / 3: 重编；只聚焦没写内容 → 还原为空（「1: 」不算有效内容，也不把「现场发现问题」算成已填 —— 前置开关照旧）。
- **「现场问题也要同上」**：现场发现问题并进同一套（预置 / 续号 / 重排 / 自动下扩），提交前统一重排后再落库，自动生成的问题标题同文本。
- **分点提示撤回**：图 4 的 1: / 2: / 3: 静态提示曾复落到两个多行框、并随「也要同上」扩到第三框，随后按「有了自动的扩展 那这个提示就不要了」整体下架（回放 ② 组改为：全表单 0 处提示 + 空框聚焦预置 1: + 失焦还原空）。
- **自动下扩 = GrowingTextarea**：四个多行框（当日完成工作 / 明日计划 / 现场发现问题 / 解决方案或建议）高度随内容长（下限 = 原 rows 行），不出内滚动条（回放 ② 组实测 58 → 118px、scrollHeight = clientHeight）。
- **静态演示数据 = 所有项目共用一份**（业务口径「写点静态数据到日报的一系列记录里面去」）：`data/reports.ts` 的 `reportsForProject` / `issuesForProject` 不再按项目过滤 —— 演示日报 6 → **9 篇**（2026年9月14日 ~ 9月21日，覆盖 已提交 / 补填 / 草稿）、问题 5 → **7 条**（未分组 1 / 未解决 2 / 处理中 2 / 已完成 2）；演示附图由「只有名字」改**内联 SVG 占位图**（`data:image/svg+xml`，离线可用、色相按名字散列），「日报记录」附图列的大图瓦片对静态数据同样成立；回放 ④ 组实证：本批提交 1 篇 + 静态 9 篇 = **10 行**、最旧 = 2026年9月14日。
