# LibiaoLink 前端功能需求（后端开发参考）

> 面向后端 / 接口开发同学。现状：前端原型已完成（分支 `px`，commit `4446f33`），项目数据为浏览器内存示例；本文档描述**已实现的页面与功能**及**所需后端接口**，用于后端开发与联调对接。

## 一、页面与交互（前端已实现）

### 1. 登录与会话

- 前端不承接登录表单：未认证自动跳转公司统一登录（Casdoor，标准 OIDC）。
- 登录回跳后通过 `/auth/me` 获取当前用户，顶栏展示姓名 + 企业邮箱，并提供「退出登录」（SSO 单点登出）。
- 账号口径遵循公司接入标准：`Name = 工号`（如 `zhangsan`）、`DisplayName = 张三`、`Email = zhangsan@libiaorobot.com`。

### 2. 首页「项目空间」

- 项目卡片网格：每行 4 列，按屏幕宽度自适应降列（1 / 2 / 3 / 4 列）。
- 卡片内容（自上而下）：
  - 右上角序号徽标（浅灰底、两位序号）
  - 小车图标（颜色随项目主题色）+「项目经理：xxx」
  - 项目编号（等宽字体，如 `CNBJ-20260708-0001`）
  - 项目描述（如「中国包裹分拣」）
  - 右下角更新时间（`YYYY-MM-DD HH:mm`）
- 悬停：卡片轻微放大 + 主题色光晕。
- 标题区：`项目空间` + 项目计数（搜索时切换为「找到 N 个项目」）。

### 3. 搜索

- 输入即过滤（实时），匹配范围：项目编号 / 描述 / 更新时间 / 项目经理。
- 一键清空；无结果时显示空态与「清空搜索」按钮。

### 4. 新建项目

- 点标题区「新建项目」按钮打开居中弹窗。
- 表单三项：项目编号、项目描述、项目经理；三项均必填（全部填写后「创建项目」才可点击）。
- 关闭方式：取消按钮 / Esc / 点击遮罩。
- 创建成功后：新项目追加到列表末尾；序号、时间（当前时刻）、主题色由前端自动分配。

## 二、前端数据模型（当前内存态）

| 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|
| id | string | 唯一标识 | cnbj-0001 |
| index | string | 展示序号（两位） | 01 |
| title | string | 项目编号 | CNBJ-20260708-0001 |
| description | string | 项目描述 | 中国包裹分拣 |
| manager | string | 项目经理 | 李伟 |
| updatedAt | string | 更新时间（展示用） | 2026-07-08 08:15 |
| accent | 枚举 | 主题色：blue / emerald / amber / rose / violet | blue |

## 三、后端接口需求（建议契约）

统一前缀建议 `/api/v1`，JSON；认证复用现有 OIDC 会话（HttpOnly Cookie 或 Bearer 均可，前端当前用 Cookie）。

### 1. 项目列表 `GET /api/v1/projects`

- query：`keyword`（可选，服务端过滤，语义同前端）、`page`、`pageSize`（建议默认 20）
- resp：`{ "items": Project[], "total": number }`

### 2. 新建项目 `POST /api/v1/projects`

- req：`{ "title": "...", "description": "...", "manager": "..." }`
- 建议服务端校验 `title` 唯一；`updatedAt` 由服务端生成（ISO 8601 带时区，前端本地化显示）
- resp：201 + 完整 Project 对象

### 3. 后续建议（前端尚未实现，接口预留）

- `PATCH /api/v1/projects/{id}`：编辑（描述、项目经理等）
- `DELETE /api/v1/projects/{id}`：删除
- `GET /api/v1/projects/{id}`：详情

### 4. 已有接口（前端已接入，无需新增）

- `/auth/login`、`/auth/callback`、`/auth/me`、`/auth/logout`（本地开发为 Vite 中间件，生产环境需按 `frontend/README.md` 迁移到后端实现）

## 四、字段校验与规则

| 字段 | 必填 | 规则 |
|---|---|---|
| title | 是 | 建议格式：四大写字母-日期-四位序号（如 `CNBJ-20260708-0001`）；建议全局唯一 |
| description | 是 | 中文短语，建议不超过 30 字 |
| manager | 是 | 姓名 |
| updatedAt | 只读 | 服务端生成 |
| accent | 只读 | 服务端下发或前端分配（待确认，见第六节） |

## 五、非功能需求

- 排序：默认按 `updatedAt` 倒序或创建顺序（待确认；原型为创建顺序）。
- 分页：项目数量增长后必须分页（原型为全量渲染 20 条）。
- 搜索：建议服务端过滤（前端当前为本地过滤，仅适用小数据量）。
- 错误处理：接口失败时前端需要提示（原型未实现，接口就绪后补）。
- 时区：统一 Asia/Shanghai；时间字段建议 ISO 8601 带时区，前端本地化展示。
- 权限：新建 / 编辑 / 删除的权限模型待定（建议接入 Casdoor Roles / Permissions）。

3. 新建 / 删除权限：按组织、部门还是角色控制？
