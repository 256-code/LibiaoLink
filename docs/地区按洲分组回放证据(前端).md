> 口径：业务定案 2026-09-28 —— 「我觉得这里太乱了 要根据各个州分类 可以展开 这边要改那新建项目选择地区应该也要改 是不是要加一个国家地区选择器可搜索的那种」；同日追订 —— 「新建地区手打容易出问题吧 还是改成搜索选择器吧 同时筛选比如某一个洲点击可以直接筛选整个洲」→「筛选框不要改成那样的 改成这样的（动效复选框参考代码）放在筛选框最右侧即可 点击选择复选框就是筛选此区域」→「复选框太大了 要小一点 迷你一点」→「新建项目里面的地区想改成这样的 不支持手填和 删除 直接改成这样的搜索选择器 图片是英文的 我要中文的 只要选择项目 不要添加地区了 只要直接选择即可」。

## 洲归属口径（与地图同源，不另起第二套国名）

- 生成物 `frontend/src/data/worldMapContinents.ts`（勿手改；改口径改脚本重跑）：扫描 `worldMap.ts` 里出现的 **201 个 ISO 3166-1 数字码（172 国 + 29 微国）** → 洲；生成时对不上（缺编码 / 查不到洲）直接报错，口径漂移会先炸脚本。
  - 洲分布：亚洲 47 / 欧洲 45 / 非洲 56 / 北美洲 25 / 南美洲 13 / 大洋洲 15。
  - 数据源：world-countries@5.1.0（MIT，构建期取数，不进前端产物）—— 与底图中文国名同一份；`Americas` 按 `subregion === "South America"` 拆南美 / 其余北美；法属南部和南极领地（260）按属地归非洲（数据源标 Antarctic，人工例外表）。
- 手写口径层 `frontend/src/data/regionContinents.ts`：认国家复用地图的 `matchRegion`（精确中文 / 英文名 → 宽松对，与地图悬停同一套）；认不出国家的地区（「海外」「中东」这类通用条目 / 自建地区）归「其他」；中国国内大区（华北 / 华东 / 华南 / 华中 / 西南 / 西北 / 东北）与中国同归亚洲。
  - 当前 43 条 enabled 字典条目全部落在六大洲（下拉里没有「其他」小标题）；侧栏在用地区 42 个同样全部落在六大洲。
