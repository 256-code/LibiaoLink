## 口径说明

- 「主标签栏自身 59px」= `pt-3`（12）+ 标签按钮（`py-3` 12×2 + `text-sm` 20 + `border-b-2` 2 = 46）+ 容器底边 1；设计位叠位常量 **123 = 64 + 59**，两层吸顶实际用 **122（向上多叠 1px）** 写在 `TaskBoard.tsx` 与 `ReportIssuePanel.tsx` 的吸顶类上 —— 断言升级为**缝不变量**「叠层 top ≤ 主标签栏下沿 − 下边框宽」（回放 ⑥ 组两处），改高度 / 改叠压都会直接红。
- **接缝口径（Push 201 补 · 业务口径「这个中间有条缝可以有办法解决一下吗」）**：吸顶条下边框在带缩放的屏（Windows 150% 等）会被按设备像素吸附成 **0.67px** —— 栏高 59 → 58.67、下沿实际落在 122.67；下方吸顶元素钉 123 就露 **0.33px 缝**（滚动时白行 / 蓝徽章从缝里闪过）。修法 = 叠层 `top` 122 + 项目总览表头 `z` 19（低于主标签栏 z-20：叠压时下边框仍画在表头上、边界保持一条实线）。150% 缩放口径复验：修前 `headTop 123 > barBottom 122.667`（缝 0.33px，接缝行像素 `255,255,255` 白行 + 蓝徽章残影）；修后 `headTop 122 ≤ 122.667`（叠 0.67px，接缝行 `250,250,250` 表头实色、无白行）；日报及问题页内导航栏同口径（修后 `subTop 122 ≤ 122.667`，无白行）。
- 键帽投影口径（em，13px 字号）：7 层侧壁最深 `0.425em ≈ 5.5px` + 末层落影 blur `0.5em ≈ 6.5px` ≈ **12px**；下内衬 16px 把整条投影兜进横幅（回放断言 nav 底 - 键帽底 ≥ 12px，实测 16px）。
- 「问题看板」放大镜按业务口径**不照搬**：原 SVG 的 24 视框 / 黑填充 / SVGRepo 外壳都去掉，只留 path —— `fillRule="evenodd"` 保住镜圈内孔，`fill="currentColor"` 随字色（当前项黑字、未选项中灰）。
- 本刀**无 DDL / 无契约改动、无新增运行时依赖**；`npm run typecheck` / `npm run build` 全绿（包体 650.35 kB）。
