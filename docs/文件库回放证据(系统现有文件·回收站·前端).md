## 追订三刀（2026-10-09）

- **① 提示改屏幕上方浮空 Toast（2s）**：新 `frontend/src/components/Toast.tsx`（`createPortal` 挂 body、`position=fixed`、`left-1/2 top-4 -translate-x-1/2`、`role=status`）—— 停留 2s 自动消失、右侧「关闭」可立即收起，同一位置再出提示以新文案重新计时。文件库页写口反馈（恢复 / 彻底删除 / 预览不可用 / 下载失败）全走它；同批接到 App（项目加载 / 删除 / 项目经理修改失败）、模板页（节点库 / 模板写入失败）、工作台（醒目模式 / 折叠记忆 / 问题状态失败）、干系人面板（写失败）、项目详情（工具失败）、首页（无权限新建提示 / 收藏筛选保存失败）。**加载失败 + 「重试」这类常驻状态提示仍留页内**（`data-file-error` / `data-audit-error` / Home `loadError` …）；删除确认条仍在底部固定条、不自动消失。
- **② 点预览不再抖表**：根因 = 表格是自动布局，「预览 → 打开中…」「下载 → 下载中…」文案变宽 → 整表列宽重排（可见横向抖动）；修复 = 操作列两钮**定宽** `inline-flex w-16 items-center justify-center` + 忙碌文案缩到「打开中 / 下载中」。护栏 = 断言 12（换文案前后宽度相等）。
- **③ 「类型」列与筛选撤除**：库内文件没有类型绑定点（实测 `files.doc_type` 全为 null —— 69 / 69 行空），列恒「—」、筛选恒空；表格七列 → **六列**（文件名 / 状态 / 项目 / 上传人 / 时间 / 操作），筛选条去掉「全部类型」，地址位状态删掉 `docType=` 参数（`FilesQueryState` / `parseFilesQuery` / `buildFilesHash` 同批收敛；旧链接带 `docType` 按不认识的值丢弃、不报错）。任务侧「输出成果文件」是任务字段，不受影响。护栏 = 断言 5。

## 追订 · 筛选多选 / 触发器 / 项目列（2026-10-09）

- **④ 筛选多选（业务口径「要可以多项选择 再次点击取消选择」+「别的筛选也是同理 要支持多选」）**：文件库项目 / 状态 / 上传人三枚下拉改 `components/SearchSelect.tsx` 的 `mode="multi"` —— 点选项勾选、**再点取消选择，点选不关闭浮层**；地址即状态并升级为逗号多值（`project=<id>[,<id>…]` / `status=<k>[,<k>…]` / `uploadedBy=<id>[,<id>…]`，去重保序，`parseAuditIdList` / `parseAuditEnumList`）。取数口径：**状态 / 项目走服务端多值**（`filter[status]` 逗号多值、逐项目并集），**上传人走前端内存过滤**（服务端 `filter[uploadedBy]` 仍单值 UUID；本页已逐项目取满全量，内存过滤等价且多选不翻倍请求；多值口径列入《前端功能需求》§3.8 A34）。护栏 = 断言 11~23（状态 / 项目 / 上传人各自的「勾选 → 累加 → 取消 → 清空」四段与库内并集对账）。
- **⑤ 触发器文案（业务口径「不要这样显示太丑了 可以只显现这个筛选的名称 然后数量淡灰色的」）**：多选触发器只显示**筛选名称 + 浅灰数量**（空选只显示名称；`SearchSelect` 的 `label` 属性 + `data-select-trigger-label` / `data-select-trigger-count` 回放钩子），不再拼「已选 N 个项目」长文案。
- **⑥ 项目列排版（业务口径「项目名称要编号和名字都写在表格里面注意排版」→「中文和编号的位置反一下」）**：项目列 = **上行中文项目名（font-medium、超宽截断出 title）、下行项目编号（浅灰小字）**；包一层 `data-file-project` / `-name` / `-code` 钩子供回放断言（护栏 = 断言 6）。同款排版同步到操作记录页项目列。

## 怎么验的（不是看截图就算数）

- **对账对的是库**：页面「共 N 条」/ 首屏行序逐次与 PostgreSQL 直查对账（在库四档 = `status in (draft,final,changed,archived)`、回收站 = `status=recycled`；排序 = `created_at desc, id asc`）；行序断言用逐行 id 串比对，不靠肉眼。
- **写口是真实调用**：⑦ 恢复走 `POST /files/{id}/restore`（断言 DB `status` 回退 + `audit_logs` 留痕）；⑨ 彻底删除走 `POST /files/{id}/purge`（断言文件行 / 版本行清零 + 审计留痕 + 对象一并清理）；⑩b 复查文件 / 版本 / 未撤销会话全 0 行。
- **浮动提示是量出来的**：`getBoundingClientRect` + `getComputedStyle` 断言「屏幕上方居中浮空」（`position=fixed`、top ≤ 120、水平居中 ±40px）；到点复查元素已从 DOM 消失（停留 1.5s ~ 5s 区间内）—— 不是按截图目测。
- **抖表是 DOM 宽度断言的**：把按钮文案换成忙碌态（同真实交互的 DOM 变化）再量 `getBoundingClientRect().width`，宽度必须相等（自动布局表格不重排）；文案换回后再继续跑后续断言（不留副作用）。
- **零残留**：跑完文件 / 版本 / 未撤销会话全 0 行；上传会话行是历史台账（保留）。
