## 备注 / 决策记录

- **任务行口径 = 照项目页任务表「搬」（只读）**：任务描述（名称 + 阶段 / 英文名小行 + 四格进度点 `TrackerDots`）/ 分组签 / 负责人（玻璃小胶囊，空 = 待分配）/ 状态胶囊 / 紧急重要度 / 「是否按时交付」（`displayStatus==="overdue"` → 「逾期未交付」红签）/ 开始 · 预计 · 实际三列日期胶囊（`M月D日`，空落「—」）；工作台无任何写入口（读面不带任务 version，属刻意）。
- **进度点换算**：契约 `progress` 为 0–1 四档小数（非 0–100），页面按 `Math.round(progress * 100)` 进四格点 —— 回放夹具 0.5 → 50% 档实证。
- **六列后两列的回填口径**：聚合读面 `WorkspaceIssueItem` 不含 `solution` / `photos` → 页面按项目并行取 `GET /projects/{id}/issues?limit=200`，按 issue id 对齐回填「解决方案或建议」「问题附图」；单项目失败 → 该项目两列落「—」+ 顶部 amber 降级提示条（`data-workspace-issue-partial`），不遮挡其它项目（回放 ⑥e3 断言无降级）。
- **标签走地址**：缺省「我的任务」不落参数、另一枚 = `?tab=raised`（`replace` 不新增历史）；未知值落回缺省且**地址不纠正**（与 `?view=` / `?sub=` 同口径，回放 ⑦b）。
- **项目序**：任务标签按三组首次出现序（已逾期 → 今日 → 即将）；问题标签按未关闭优先；**同日并列的排序服务端不保证稳定**（回放 ⑤c / ⑥b 按顺序无关断言，见「已知边界」）。
- **色表导出**：`TaskBoard.tsx`（`STATUS_CAPSULE_CLASS` / `PRIORITY_CAPSULE_CLASS`）与 `ReportIssuePanel.tsx`（`ISSUE_TAG_CLASS` / `ISSUE_CATEGORY_CLASS`）各加 2 行 `export`，工作台与项目页共用同一份色表，避免两处漂移。
- **零残留口径**：两个临时项目物理删（连同任务 / 日报 / 问题）；问题附图先回收（recycle）再彻底删除（purge）后随项目删；两条临时会话撤销（uuid 打标）。`audit_logs` 只读不动。
- 页面控制台 / 未捕获异常：0 条。
