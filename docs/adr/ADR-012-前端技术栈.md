# ADR-012 前端：React 19 + Vite 8 + Tailwind 4 + 自研组件（headless 优先）

- 状态：草案（Proposed）｜评审：lan、px｜随 PR 合并 main 后转「已采纳（Accepted）」
- 日期：2026-09-18｜决策人：wmj（技术负责人）
- 依据：技术设计v0.1-选型分析.md §0.1、§4.9、§5（#13）；仓库 frontend/ 现状；Q14

## 背景

仓库已有 React + Vite 原型与自研视觉体系；一期含重交互页面（万行级任务表、看板、仪表盘、文件与预览、流程节点界面），甘特图已确认移出二期。

## 决策

- 基础栈（与仓库现状一致）：React 19 + Vite 8 + TypeScript（严格模式）+ Tailwind CSS 4 + 自研组件；按需引入 headless primitives（Radix / Headless UI 候选，随 Q14 评估）。
- 配套库：TanStack Query 5（服务端状态，不建实体副本）、TanStack Table + Virtual（任务表虚拟滚动 + 自研单元格编辑）、React Hook Form + Zod（与后端契约同源）、Apache ECharts（仪表盘 / 大屏）、dnd-kit（看板拖拽）、dayjs；i18next 预留不启用。
- 不引入 Ant Design 等第二套设计语言。
- 表格升级路径：AG Grid 商业版仅在出现多级表头 + 列冻结 + 公式 + 透视等重需求时评估。
- 甘特图：二期实施（自研 SVG 路线；DHTMLX 仅当二期确认需要基线 / 资源平衡时评估）；一期以表格 + 看板呈现进度。
- 工程约束：服务端数据唯一真相；写冲突返回 409 并保留用户输入；错误边界与骨架屏；组件级权限只做展示控制。

## 备选与不采用原因

- AG Grid Community：社区版缺分组透视与导出（商业版才有），深度定制受约束。
- Ant Design Table：组件完整但引入第二套设计语言。
- Handsontable：商业授权限制（非商业许可不可用于内部经营系统）。
- DHTMLX / Bryntum：甘特二期再评估，一期不采购。

## 影响与后果

- 前端产能是一期瓶颈之一（1 人）：表格自研（约 1~2 周）与页面接线并行推进；甘特移出降低风险。
- 契约驱动：前端类型来自 Zod / OpenAPI 生成物，禁止手写（CONTRIBUTING §14）。

## 切换触发条件

表格需求超出自研范围（多级表头 / 列冻结 / 公式 / 透视），或甘特二期启动。
