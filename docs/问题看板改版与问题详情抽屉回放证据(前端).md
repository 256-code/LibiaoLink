## 决策记录

- **列壳 / 卡片同款 = 直接复用任务进展看板的类口径**（不另起一套）：`ISSUE_COLUMN` 与 `COLUMN_SHELL` 同值（`w-[280px]` + `h-[calc(100vh-12.75rem)]` + `max-h-[52rem]` + `min-h-[22rem]`），卡片 = `CARD_SHELL + CARD_NOISE + CARD_BODY`（白壳 + 35px 圆角 + 三层投影 + 发丝边 + 6% 细纹）；原「灰底面板」列壳整体下架。回放实测（⑨ 组）：列宽 280 / 列高 796（1000 视口）/ 列底色 `rgba(0, 0, 0, 0)` / 零描边 / 卡片圆角 35px / 阴影三档逐字对齐。
- **卡面只出问题内容四段**（业务样「图一」）：状态签 / 提出人 / 提出日期从卡面整体下架 —— 状态由「列头色签 + N 项」表达、其余进抽屉折叠区（Push 207 的「责任 / 处理时限 / 所属任务」不展示口径照旧）。回放实测：i-01 卡面 = ⑧ 组行内编辑后的现值（描述 / 解决方案 = `NUMLINE(...)`）· pre-line · 归类色签 1 枚 `rgb(255, 234, 153)` · 附图 2 枚 40×40 · 状态签 / 提出人 / 日期词零残留。
- **点卡片 = 问题详情抽屉**（业务样「图二」）：壳 = 任务抽屉同一套（`drawer-backdrop` / `drawer-panel` 全局动画类 · 460px 右滑入 · `role=dialog` + `aria-modal` · `lockBodyScroll`）；上半 = 问题本身四行、中间 = 「˅ 已隐藏 · 6」（默认收起、点开出 6 枚次要字段）、下半 = 来源日报七行（当日完成工作 / 日期 / 填写者（姓名头）/ 明日计划 / 现场工作附图 128×96 / 问题是否处理（状态色签）/ 施工人数）；footer 标「来源日报：r-0921a；点空白处或按 Esc 关闭」；Esc / 点遮罩关闭后页面滚动解锁（实测 `body overflow` 回空串）。
- **关联展示 = `Issue.reportId` 现找来源日报**（现读内存态）：⑧ 组刚编辑过 r-0921a 的「当日完成工作 / 明日计划」，⑨ 组抽屉下半即刻显示编辑后的 `NUMLINE` 文本 —— 「行内编辑 → 看板 → 抽屉」同一份内存态串起来（无新增字段）。
- **隐式滚动条**（看板列内卡片 / 列间横排）：与任务进展看板同走 `ScrollArea`（原生滚动条隐藏、滚动 / 悬停才浮出自绘滑块）；回放实测看板内 `[data-scroll-area]` = 4 处（3 列内 + 1 横排）。
