- **参数形态 = `?view=daily&sub=<slug>`（ASCII）**，与主标签 `?view=` / 任务模板 `?section=` 同一套「默认值不进 URL + 地址即状态」口径：缺省「日报填写」form 不落参数 —— 旧链接 / 书签 `?view=daily` 原样打开仍是日报填写，零兼容成本。

- **子视图切换不重置内容**：`ReportIssuePanel` 的日报 / 问题内存态与填写草稿挂在面板自身上（`key = project.id`），子视图只是地址投影 —— 切块不丢草稿 / 不丢刚提交的行；提交后自动切「日报记录」也走同一写入口径（③ 组实读 `sub=records`）。
