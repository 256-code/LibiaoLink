## 汇总

- **41 / 41 项全过**（脚本自清理：任务软删 → 项目硬删 → 节点物理删 → 临时会话撤销，库内零残留）。
- 关键口径：① **建完即开抽屉** —— 创建成功拿新任务 id 直接 `setSelectedTaskId`，抽屉按 id 从最新列表取行（建完未刷新也能等到列表刷回来自动开），新建浮层照旧立即关；
  ② **改名只对无来源节点任务开放** —— 抽屉里出「任务描述」行（中文必填 / 英文可留空；失焦即存、值没变不写、中文留空自动还原不写库、英文留空发 `null` 清空）；节点 / 模板生成的任务抽屉里**不出这一行**，服务端同口径 400 兜底；
  ③ **垫底分组** —— 「临时任务」与九阶段一样常显骨架、永远垫底，组头胶囊不是按钮（点它 / 点那一段空白什么都不发生），九个施工阶段的标签照旧可开可关（脚本内有对照组）。
