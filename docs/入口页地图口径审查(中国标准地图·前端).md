## 四、符号层（一）：微国 —— 110m 精度画不出的 29 个主权国家

业务复核时问「**新加坡为什么标不出来**」。根因不在代码，在数据精度：底图的世界国界取 Natural Earth **1:110m**（图宽 1000 视口单位 ≈ 1:1.1 亿），
新加坡、巴林、马耳他这一档的国家本体，比 110m 数据里**最小的多边形还小** —— 数据源里根本没有它们的几何（新加坡还整个并进了马来西亚那块）。
用 `world-countries`（194 个主权国）逐条比对 110m 的 177 个几何：**缺 29 个主权国家**，分别是 ——

安道尔、安提瓜和巴布达、巴林、巴巴多斯、科摩罗、佛得角、多米尼克、密克罗尼西亚联邦、格林纳达、基里巴斯、
圣基茨和尼维斯、圣卢西亚、列支敦士登、摩纳哥、马尔代夫、马绍尔群岛、马耳他、毛里求斯、瑙鲁、帕劳、
新加坡、圣马力诺、圣多美和普林西比、塞舌尔、汤加、图瓦卢、梵蒂冈、圣文森特和格林纳丁斯、萨摩亚。

处理办法：按**形心点位**补一个圆点符号（生成物里的 `WORLD_MAP_MICRO_STATES`，前端画成圆点 + 白镶边），触碰同样提亮 + 报国名；**没项目的微国是灰点，有项目的微国按业务 2026-09-24 五追订指定为蓝点；七追订改成分档随数据算 —— 有项目的国家 / 微国按项目数上蓝色底（最多 5 档、项目越多越深，色阶 5 档 `#c8dcfc → #2f6fe0`，业务给的那个蓝 `#4285f4` 落在最深端这一族）**。
世界尺度下这是唯一画得出来的表达 —— 标准地图对这类小国也是靠符号 / 附图表现，不是画疆域。

| 项 | 口径 |
|---|---|
| 判定规则（写死在生成脚本里） | `world-countries` 里 `independent === true` **且** 110m 里没有几何的国家 |
| 硬护栏 | 另有 DENY 兜底：台湾 / 科索沃这类实体要是被上游标成独立国，生成**直接报错**；条数一旦不等于 29 也报错，逼人来重审 |
| 台湾在不在里面 | **不在**。world-countries 里台湾 `independent = false`，且 DENY 名单里有 TWN / XKX，中文名再挡一道（台湾 / 臺灣 / 科索沃 / 北塞浦路斯 / 索马里兰） |
| 为什么不换高精度数据 | 换 10m / 50m 要重做整份底图（体积、性能、抽稀全变），且新加坡在 110m 尺度下本来就画不出来；**符号是标准做法**，不是权宜 |
| 符号是不是「蓝点」 | 不是。业务说的「参考图的蓝点」是装饰性定位点，已有断言禁止（除微国 / 南海诸岛两组符号外，图上的 `circle` 数量必须为 0）；这里每个点都代表一个主权国家、可触碰报国名。**2026-09-24 五追订另行指定：有项目的国家 / 微国用「图二的这种蓝」（#4285f4）表示，那是业务给的数据含义、不是装饰；六追订（方案 E）把这一层改成按项目数上底色；七追订（「这个颜色深浅不能按照固定的数据来 到时候所有地区大于3个不就是同一个颜色了吗」）再把档位改成随数据自适应 —— 同档同色、项目越多颜色越深、最多 5 档，那个蓝落在最深端这一族** |
| 密集区重叠 | 加勒比（安提瓜 / 圣基茨 / 圣卢西亚 / 圣文森特 / 格林纳达 / 多米尼克 彼此相距几像素）与欧洲（梵蒂冈 / 圣马力诺相距约 5 视口单位）会挨在一起，按画序取最上层那个 —— 世界尺度下的固有限制，逐条登记 |
| 中文名 | 数据源把**多米尼克**写成了「多米尼加」（与多米尼加共和国撞名），已在 `ZH_OVERRIDE` 修正；密克罗尼西亚按外交部口径写「密克罗尼西亚联邦」 |
| 点位来源 | `world-countries` 的 `latlng`（国家形心 / 首都），落在视口外会直接报错 |

回放脚本里的固化断言（`frontend/scripts/ui-hub-map-e2e.mjs`）：微国符号恰好 29 个、每个都带国名、不重名、不跟国家路径重名、都在视口里、
**真实鼠标停在新加坡能命中该符号**（不是被马来西亚那块盖住）、徽标报「新加坡 Singapore」；**没项目的**微国静止态填充 `rgb(182, 190, 204)`、触碰态 `rgb(124, 134, 152)`；**有项目的**微国按项目数上蓝色底色（档位随数据算：新加坡 1 个 = 第 1 档 `rgb(200, 220, 252)` + 深蓝镶边），触碰压到最深触碰色 `rgb(26, 115, 232)` + 白镶边。

## 五、符号层（二）：南海诸岛 —— 群岛代表点 5 点（对照标准地图 EPS 补齐；业务口径「细小的岛屿不用列」）

业务给来中国标准地图 EPS 原件后逐块比对，最扎眼的一处差距就是这里：**标准地图在世界地图上把南海诸岛点出来了**（我看到的是一串小岛礁符号 + 断续线段），而本图此前只有断续线、诸岛本体因为过不了碎岛阈值（面积 < 1.5 视口单位²）被整片删掉，图上就是一片空海。

处理办法与微国符号同源：从**同一份中国国界（DataV）**里挑出三沙市那些岛礁环；业务口径「细小的岛屿不用列」→ **不逐岛列，一个群岛一个点**：把每个群岛范围内的岛礁环合起来取形心，单列成 `WORLD_MAP_NANHAI_ISLANDS`（**5 点**：东沙 / 西沙 / 中沙 / 南沙 / 南沙南部·曾母暗沙一带），前端画成比微国符号更小的灰点（半径 1.4 视口单位）、**触碰报「中国」**。

| 项 | 口径 |
|---|---|
| 点位来源 | DataV 中国国界（`100000.json`）里的岛礁环，**不手写坐标**；一个群岛的形心即该群的符号位置 |
| 选区 | 一个群岛一个框（东沙 / 西沙 / 中沙 / 南沙 / 南沙南部·曾母暗沙一带）；环的包围盒要整只落在框内，才算这个群的 |
| 群内怎么取点 | 一个群岛一个点：该群岛框内所有岛礁环的点取算术平均（形心）；每个群的环数 / 点数在生成日志里逐群打印（东沙 / 西沙 / 中沙 / 南沙 / 南沙南部 各一行） |
| 与断续线段怎么分 | 断续线段在国界里又重复画了一遍（形状与 `100000_JD` 那份完全一致），按**包围盒重合**剔掉，不靠肉眼调阈值 |
| 为什么不做附图 | 标准地图是用角落附图放大表现诸岛的；入口页是示意底图、面板尺寸有限，先按标准地图「点出来」的习惯做到可见可触碰，附图另议（第六节第 4 行） |
| 报什么国名 | 「中国」—— 直接取国界层里中国那条记录，**不另造「南海诸岛」这种实体词条**，与台湾同口径 |
| 硬护栏 | 条数一旦不等于 5 直接报错；**哪个群一个环都找不到也直接报错**（上游数据一变就报错，逼人重审） |

回放脚本里的固化断言：5 个群岛代表点 / 5 个命中区、都在视口内且落在南海这一片、静止态填充 `rgb(182, 190, 204)`、`data-country` 为「中国」、**真实鼠标停在最南那一点能命中**、触碰态填充 `rgb(124, 134, 152)`、徽标报「中国 China」。
