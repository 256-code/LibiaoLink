## 已知问题（随本批登记，挂线不在本刀修）

1. **后端真 bug（wmj 线 · project 模块）**：`ProjectRepository.hardDeleteWithVersion` 先删 `file_versions` 再删 `files`，而 `files.current_version_id → file_versions(id)`（`fk_files_current_version`）挡着 —— 项目里有「已完成版本」的文件时，物理删项目 500（`violates foreign key constraint fk_files_current_version`）。回放脚本用「文件 recycle → purge → 删项目」绕过（`purgeProjectFiles()`）；修复方向 = 删除顺序改为「先清 `files.current_version_id` / 先删 `files` 再删 `file_versions`」。
2. **预览产物缓存边界（lan 线 · preview）**：预览产物缓存键 = 内容哈希 + 管线版本 + 通道；同一张图在新上传后若产物被清而 outbox 的 `done` 行仍在，读面会停在 `not_ready`。回放用「每轮随机像素」规避（`pngBytes()`）；是否要在上传 / 清理链路里失效 `done` 行请 lan 复核。
